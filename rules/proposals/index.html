Proposed Rule Amendments and Adoptions

The Michigan Supreme Court publishes proposed changes to the Michigan Court Rules, Rules of Evidence, Rules of Professional Conduct, Rules Concerning the State Bar, Code of Judicial Conduct, and other administrative rules. You can comment on any open proposal before the Court takes final action.

About this page

Each proposal shows its ADM docket number, the action being taken, a plain-language summary, and a link to the full proposal. Proposals are listed newest to oldest. After a comment period closes, the proposal stays here for reference.

The Court must consider all timely comments before it issues a final order. Final orders are published separately in the Court's administrative orders.

Submit a public comment

You'll need the ADM number of the proposal you're commenting on.

Submit a comment

Staff review each submission. Comments that aren't frivolous are usually added to the public record within a few days. Anonymous comments are accepted.
